# Appointment Slot Booker

A single-page React application for booking clinic appointments, built with React, Vite, TypeScript, and Tailwind CSS.

## How to Install and Run

This project requires [Node.js](https://nodejs.org/) to be installed. Use the following commands to install dependencies and start the local development server. You can copy and paste these directly into your terminal:

```bash
# Install all required dependencies
npm install

# Start the Vite development server
npm run dev
```
